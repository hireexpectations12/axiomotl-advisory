# Axiomotl hero refinement

Scope supplied by user: “yah apply it to the hero section”. Retain the established purple identity, exact content, artwork, links and five workflow cards. Prior user constraint: very small gap below the cards.

Implementation decisions based on the existing site: restrained, dimensional, clear. This is a hero refinement, not a full-page cinematic rebuild. Existing assets provide environment, signal lines, focal artwork and foreground workflow cards. No generated assets required.

Journey and feeling: opening provides orientation through the stable headline; short natural scroll separates the environment and artwork, suggesting complexity becoming legible; the cards resolve into a practical route into the next section. Peak is the separation of artwork from its background, without a second headline or content change. Signature: the existing decision-system illustration advances while its evidence field recedes.

Layer contract: environment moves 36px down; artwork moves 18px down and scales from 1 to 1.025; signal plane moves 12px up. Text, actions and workflow stay stable. No pinning, added height or intentional blank scroll. Mobile retains a static composition. Reduced-motion and the existing Motion off control retain the same complete static hero.

Assets and typography: reuse existing brand artwork and Lato. No invented claims. Existing dark purple, white type and muted lavender remain the palette. Restrict all changes to the hero. Native CSS view timeline is progressive enhancement; unsupported browsers show the static composition.
