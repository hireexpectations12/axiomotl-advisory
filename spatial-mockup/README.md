# Axiomotl spatial mockup

Open `index.html` directly, or serve the project root and visit `/spatial-mockup/`. The project-root `axiomotl-spatial-mockup.html` is the standalone export: it embeds the same CSS, JavaScript, logo and fonts in one file for sharing and offline use.

The hero is a five-stage method explorer. Select a satellite, use the previous/next controls, or use arrow keys when a stage has keyboard focus. Fine pointers move the spatial model. Motion can be disabled and follows the operating system's reduced-motion preference. Services expand using native disclosure controls. Contact links open an email draft; the mockup has no submission backend.

The supplied logo and the site's service and practitioner facts come from the original `axiomotl-advisory-v2.html`. No client results or testimonials are invented. The original logo is displayed in monochrome using CSS.

Visual direction: white, Oxford Blue `#002147` and Ice `#ECF2F7`, with soft material shading derived from those colours. Sora is used for display type and Manrope for body type; both are stored locally from Google Fonts. GSAP 3.15.0 is stored locally from the public npm distribution via jsDelivr.

Animation implementation follows the official [GSAP core, timeline and performance skills](https://github.com/greensock/gsap-skills) and the [GSAP documentation](https://gsap.com/docs/v3/).
